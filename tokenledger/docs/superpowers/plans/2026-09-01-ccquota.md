# ccquota Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a single Go binary that collects Claude Code usage from every endpoint on N subscriptions, reconciles it against Anthropic's account-wide limits, and serves a dashboard plus a read-only MCP server.

**Architecture:** One binary, roles by subcommand. `agent` tails `~/.claude/projects/**/*.jsonl` incrementally and polls `/api/oauth/usage` locally, pushing both to a `hub` over HTTPS. The hub stores to pure-Go SQLite and serves an embedded SPA, a query API, and MCP over streamable HTTP.

**Tech Stack:** Go 1.25 (floor set by modernc.org/sqlite) · `modernc.org/sqlite` (no cgo) · `embed.FS` · hand-written HTML/CSS/JS dashboard (no npm build step) · stdlib `net/http` (no web framework)

**Spec:** `docs/superpowers/specs/2026-09-01-ccquota-design.md`

## Global Constraints

- **No cgo.** `CGO_ENABLED=0` must cross-compile to linux/amd64, linux/arm64, darwin/arm64, windows/amd64.
- **Dedup key is `(account_uuid, message_uuid)`** where `message_uuid` is the JSONL entry's `uuid`.
- **Never sum `usage.iterations[]`** — top-level counters are already the total.
- **The agent reads OAuth tokens, never refreshes them.** Expired ⇒ skip the poll and report staleness.
- **The hub never stores OAuth tokens.**
- **Unknown model ⇒ `cost_usd = NULL`**, never `0`.
- **Degraded limits ⇒ gauges absent + banner**, never a stale percentage rendered as live.
- Costs are **notional** (API-equivalent) for subscription users; every surface that shows one says so.
- Per-endpoint split percentages are **estimates**; the account total is exact.

## Tasks

### Task 1: Scaffold
Create `go.mod` (module `github.com/verkyyi/ccquota`; the Go floor is 1.25, set by modernc.org/sqlite), `Makefile`, `.github/workflows/ci.yml`, `internal/model/model.go` with `UsageEvent`, `Identity`, `LimitsSnapshot`, `Batch`. Commit.

**Produces:** `model.UsageEvent{AccountUUID, EndpointID, SessionID, MessageUUID, RequestID, TS time.Time, Model string, InputTokens, OutputTokens, CacheCreate5m, CacheCreate1h, CacheRead, ThinkingTokens, WebSearchRequests, WebFetchRequests int64, CostUSD *float64, CWD, GitBranch, Entrypoint, Effort string, IsSidechain bool}`

### Task 2: JSONL parser (TDD)
`internal/scan/parse.go` + `parse_test.go` with golden fixtures under `internal/scan/testdata/`.
Test first: an assistant entry with `iterations[]` yields the top-level totals **only**; a user entry yields nothing; missing `usage` yields nothing; unknown fields are ignored.

**Produces:** `scan.ParseLine(line []byte) (*model.UsageEvent, bool, error)`

### Task 3: Incremental cursor + scanner (TDD)
`internal/scan/cursor.go`, `scanner.go`, tests for: rescan is a no-op, append reads only new bytes, truncation and inode change force full rescan, duplicate uuids across forked files collapse.

**Produces:** `scan.NewScanner(root string, cursorPath string) *Scanner`; `(*Scanner).Scan() ([]model.UsageEvent, error)`

### Task 4: Pricing (TDD)
`internal/pricing/pricing.go`. Embedded table with five rates per model. Tests: 5m vs 1h cache writes priced differently; unknown model returns `nil` cost.

**Produces:** `pricing.Table.Cost(ev *model.UsageEvent) *float64`

### Task 5: Identity + credentials (TDD)
`internal/identity/`. Reads `~/.claude.json` for account fields; per-OS credential loading; expired token detection. Tests use a fixture home dir. **Never writes, never refreshes.**

**Produces:** `identity.Detect(home string) (*model.Identity, error)`; `identity.LoadToken() (token string, expiresAt time.Time, err error)`

### Task 6: Limits client (TDD)
`internal/limits/client.go`. Parses the `/api/oauth/usage` payload; contract-test fixture pinned to the observed shape; 404/500/garbage each degrade to a typed `ErrUnavailable` rather than a zero value.

**Produces:** `limits.Fetch(ctx, token string) (*model.LimitsSnapshot, error)`

### Task 7: Store (TDD)
`internal/store/`. `schema.sql` per spec §5, migrations, `InsertBatch` with `INSERT OR IGNORE` on the dedup key. Test: inserting the same batch twice yields one row set.

**Produces:** `store.Open(path string) (*Store, error)`; `(*Store).InsertEvents`, `.InsertLimits`, `.UpsertAccount`, `.UpsertEndpoint`

### Task 8: `ccquota report` — M1 deliverable
Wire scan + pricing + identity into a local one-shot report. No hub, no network. This proves the parser before anything depends on it.

### Task 9: Spool (TDD)
Bounded on-disk queue, oldest-dropped at the cap. Test: cap enforcement, survives restart.

### Task 10: Ingest API + enrollment (TDD)
`internal/api/ingest.go`, hashed enrollment tokens, `ccquota enroll`. **Isolation test: two accounts × two endpoints, assert no cross-account leakage.**

### Task 11: Agent loop
`internal/agent/agent.go`: scan → poll limits (jittered 120s, honor `limits_poll_interval_s`) → push → spool on failure. `--once` mode.

### Task 12: Reconciliation (TDD)
`internal/recon/recon.go` per spec §7. Tests: known splits, reset-boundary windows, zero-total window does not divide by zero.

**Produces:** `recon.EndpointShares(snap *model.LimitsSnapshot, evs []model.UsageEvent) []recon.Share`

### Task 13: Query API
`internal/api/query.go`: endpoints backing all four dashboard views, all account-scoped.

### Task 14: MCP server
`internal/mcp/mcp.go`: streamable HTTP, seven read-only tools per spec §8.2. Tool descriptions state the estimate/notional caveats.

### Task 15: Dashboard
`web/dist/index.html`, hand-written HTML/CSS/JS — no Vite, no npm, so `go build` alone produces the complete artifact. Four views + subscription switcher. Load the `dataviz` skill before writing chart code and run its palette validator. Degrade banner when limits are unavailable.

### Task 16: Packaging
Service unit generation, Dockerfile, goreleaser config, README with spec §10 limits stated plainly.
