# /fleet-feedback — 一句话发给 fleet 的维护者

<!-- fleet skill · owner: any session -->

这不是 Claude Code 自带的 `/feedback`（那条发给 Anthropic）。这条发给运营这个
fleet 的人：他说的一句话，加上自动带上的版本、机器类型、会话，进入口，回一个
反馈号 `F…`；处理完会回到他的会话里。所有事都由 `~/.claude/fleet/bin/fleet-feedback.sh`
做（EPIC #3354 C4）——你只负责照下面四步走，不要自己拼请求、不要自己读令牌。

他要说的话（原样，不改写、不翻译、不补充）：

$ARGUMENTS

**没有话**（上面是空的）：问他一句「想告诉我们什么？」，拿到再往下走。

## 1. 预览 — 什么都不发

把他的话原样放进带引号的 heredoc（`<<'FLEET_FEEDBACK_EOF'`，一个字都不改；这样他
话里的引号、`$`、反引号都不会被 shell 读），运行：

```bash
~/.claude/fleet/bin/fleet-feedback.sh preview - <<'FLEET_FEEDBACK_EOF'
<他的话>
FLEET_FEEDBACK_EOF
```

把输出**原样**给他看（一行都别省：原话里遮掉了什么、哪些会公开、能附上什么）。
退出码 3 = 遮不干净，什么都没发：把那句话给他看，停下，等他改了再来。

## 2. 问附不附

问一个问题，三个选项，原样用这三个标签：

- **附上** — 最近 30 分钟的日志和当前屏幕，只给管理员看，密钥先遮掉，7 天后删
- **不附，只发这句话**
- **先不发了**

Claude Code：用 AskUserQuestion。没有 AskUserQuestion（Codex）：把三个选项写成
`1 附上 · 2 不附，只发这句话 · 3 先不发了`，等他回 1 / 2 / 3。**每次都问，不替他选**，
上次的回答不算数。

选「先不发了」：回一句「好，没发。」就结束。

## 3. 发

同一个 heredoc，`preview` 换成 `send`；选了「附上」再加 `--attach`：

```bash
~/.claude/fleet/bin/fleet-feedback.sh send [--attach] - <<'FLEET_FEEDBACK_EOF'
<他的话>
FLEET_FEEDBACK_EOF
```

## 4. 告诉他结果

把脚本的输出原样转给他——它已经是给人看的话。按退出码：

| 退出码 | 意思 | 你做什么 |
|---|---|---|
| 0 | 已收到，有反馈号 `F…` | 转给他，结束 |
| 5 | 入口连不上，已存在本机，连上自动补发 | 转给他；补发后反馈号会作为一条消息回到这个会话 |
| 4 | 发太多了（每人每天 10 条、两条隔 30 秒） | 转给他，不重试 |
| 3 | 遮不干净（本机或入口查出密码 / 令牌），没发 | 转给他，等他改 |
| 2 | 这台电脑没接入口 / 入口没开反馈 | 转给他，不重试 |
| 1 | 别的错 | 转给他那一行 |

不要重试、不要换个说法再发一次、不要自己去 GitHub 开单——入口会建单，单号和处理结果
会回到他这里。
