# 成员 · 快速开始

目标：从管理员发来的邀请，到你自己的第一个会话，大约 5 分钟。你需要一台 Mac 或 Linux 电脑和它的终端（Mac 上推荐 iTerm2）。

## 1. 安装

把管理员发给你的那一行粘进终端，回车。形如：

```sh
curl -fsSL https://hub.example.com/i/<邀请码> | sh
```

它不问问题，装完会自动打开 tokenman 的客户端。

## 2. 登录

第一次打开时会让你登录：

1. 终端里出现一个链接或二维码。用浏览器打开，或用手机扫。
2. 在页面上用微信、邮箱或 GitHub 登录，点 **确认签发**。
3. 回到终端，看到 `✓ 证书 · ✓ 已登记到入口` 就好了。

登录 12 小时有效，之后这台电脑会自己续上；续不上时客户端会再请你扫一次。

## 3. 开出第一个会话

网页新会话启动时，输入框可能短暂显示「正在连接会话」：可以先写草稿，连接就绪后再发送。暂时连不上时会自动重试并保留草稿；只有确认旧版本或只读登录才显示只读，不需要重建会话。

1. 打开 ⌘P 面板，选「+ 新会话」，按 Enter。
2. 检查仓库和 Agent；不需要仓库时选「不绑仓库」。再按 Enter 打开。
3. 在新会话里说要做什么；收到回复，就走通了。

## 4. 记住一个键

**⌘P**（iTerm2；别的终端和手机用 **F12** 或 **⌃] p**）打开总面板：

- PIN 在前，普通任务直接排列，较旧记录在「更早的会话」里；搜索包含折叠历史；
- 选「+ 新会话」，Enter 打开小框：仓库和 Agent 已选好，再按 Enter 就开；开好后直接在会话里说要做什么；
- 行首只有一个状态位：`!` 需要回答、`◷` 待启动、`↻` 运行、`⟳` Loop；静止行留空。多项同时成立时按这个顺序显示；
- 要停止当前会话，选中后 Tab →「停下（可恢复）」直接请求停止，保留文件和历史。尚无运行会话的待启动请求，目前不能从这里取消。

关掉终端窗口不会停掉会话，下次在终端敲 `fleet` 回到原样。

## 在桌面浏览器打开终端

登录入口网页，在「会话」里点一行会打开该任务的**网页对话**。任务页可以查看详情、发送消息，并对当前运行会话请求「停止」。旧的 `/app/s/<会话>?view=term` 地址也会打开同一任务的对话，并提示原生终端交互应在 iTerm2 中继续；任务页没有网页终端备用模式。

网页独立的**个人 Shell** 仍可使用，地址是 `/app/s/shell?view=term`。它是命令行入口，不是任务列表的另一种展示方式。网络中断时保留最后一屏、暂停输入并尝试重连；未确认的输入不会重发。关闭网页不会停止仍在运行的 Shell 或任务。

浏览器的 **⌘P / Ctrl+P** 仍是打印，**⌘W / Ctrl+W** 仍是关闭标签页。需要原生 Agent 的终端交互、端口转发、文件传送或本地登录回调时，使用 iTerm2 等本地终端。

## 下一步

网页里的 Claude 会话用完订阅额度后，会在能安全交接时自动换 Codex 接着做，并显示一句提示。
未发出的消息会退回输入框；无法安全交接时，会保留记录并说明如何接续。网络错误、登录失败和主动停止不会触发切换。
试用账号也能使用 Codex，切换助手不会重置试用额度或延长试用时间。

- 打不开、连不上：[故障排查](../troubleshooting.md)
