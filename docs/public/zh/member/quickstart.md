# 成员 · 快速开始

目标：从管理员发来的邀请，到你自己的第一个会话，大约 5 分钟。你需要一台 Mac 或 Linux 电脑和它的终端（Mac 上推荐 iTerm2）。

## 1. 安装

把管理员发给你的那一行粘进终端，回车。形如：

```sh
curl -fsSL https://hub.example.com/i/<邀请码> | sh
```

它不问问题，装完会自动打开 fleet 的客户端。

## 2. 登录

第一次打开时会让你登录：

1. 终端里出现一个链接或二维码。用浏览器打开，或用手机扫。
2. 在页面上用微信、邮箱或 GitHub 登录，点 **确认签发**。
3. 回到终端，看到 `✓ 证书 · ✓ 已登记到入口` 就好了。

登录 12 小时有效，之后这台电脑会自己续上；续不上时客户端会再请你扫一次。

## 3. 开出第一个会话

1. 第一次列表是空的，底下写着 `No sessions — type a name`。
2. 敲一个名字，比如 `hello`，回车。
3. 右边打开一个新会话，里面是 Claude Code。给它一句话，看到回复就走通了。

## 4. 记住一个键

**⌘P**（iTerm2；别的终端和手机用 **F12** 或 **⌃] p**）打开总面板：

- 所有会话都在这里，选一行就切过去；
- 选「⚡ 新会话」，Enter 打开小框：仓库和 Agent 已选好，再按 Enter 就开；开好后直接在会话里说要做什么；
- 会话停下来问你问题时，它那一行会标出来，切过去回答即可。

关掉终端窗口不会停掉会话，下次在终端敲 `fleet` 回到原样。

## 在桌面浏览器打开终端

登录入口网页后，在「会话」里点一条正在运行的会话的「终端」，会直接打开那个会话。
侧栏和会话页上的「我的终端」打开个人终端；已结束的会话仍用「接回」。

「打开 Shell」切到持久个人 Shell。在其中运行的嵌套 Shell 输入 `exit` 或 EOF 会返回外层。
连接断了（网络、入口更新、家里机器重启、手机切到后台）页面不会放弃：最后一屏留着、暂停输入，回到前台或网络恢复时立刻再试，接回的是同一个终端；未确认的输入不会重发。
你上次看的会话结束了，再进来会回到你的个人终端并提示一句；个人 Shell 本身退出了（或家里的 tmux 没了），页面自动开一个新的个人终端——已退出的命令和 worker 不会重启。
会话的终端里那个会话结束了，页面转到你的个人终端；会话重启过，直接连上现在的它。家里机器连不上或在维护时，页面说明原因，恢复后自动连上，不用刷新。
你刚打开或点回来的那一页使用终端，另一页显示「已在另一个页面打开」，点一下就切回来。只有登录失效时需要你重新登录。关闭网页会保留仍在运行的 shell 和会话。
页面地址是 `/app/terminal`，旧的 `/term?worker=…` 链接保留目标并跳转到这里。

在支持网页终端的节点上，「Fleet 菜单」和 **Ctrl+]，再按 p** 打开原生面板；
「打开 Shell」切到 shell，再点一次返回。浏览器的 **⌘P / Ctrl+P** 仍是打印，
**⌘W / Ctrl+W** 仍是关闭标签页。连接状态显示「直连」或「经入口连接」。
断线期间的输入不会重放；粘贴中断时先检查终端，再重新输入。
会话发来的网页会显示为可点击链接；端口转发、文件传送和本地登录回调需要本地终端。
