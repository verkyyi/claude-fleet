# 日常使用

这一篇讲每天怎么用：一个键打开总面板，开会话、看状态、回答问题；出了问题怎么说。电脑和手机上怎么连，单独一篇：[电脑和手机上怎么连](connect.md)。第一次用先照 [成员 · 快速开始](quickstart.md) 开出第一个会话。

先记住一句话：**会话跑在 fleet 的机器上，不在你的电脑上。** 关掉终端、合上笔记本、断网，会话都照常干活；回来敲 `fleet`，一切原样——直接回到你上次看的那个会话（换一台电脑、在手机上也一样）；那个会话已经关掉了，就给你开一个新会话。想去别的会话，`fleet open <名称>` 或 ⌘P 里选。

## 一个键：总面板

所有事都从一个键开始。下面的表由 fleet 的按键配置生成，改了默认按键，这里跟着变：

<!-- docs-gen:keys -->
| 在哪 | 按 |
|---|---|
| Mac 上的 iTerm2 | `⌘P` |
| 手机（Termius）或别的终端 | `⌃空格` 或 `F12` 或 `⌃] p` |

| 键 | 做什么 |
|---|---|
| `↵` | 切过去 |
| `Tab` | 操作 |
| `↑↓` | 选 |
| — | 打字筛选 |
| `?` | 图例 |
| `esc` | 关 |
| `↑` | 到 ⚡ |
<!-- /docs-gen:keys -->

面板大致长这样（示例数据）：

```text
⚡ 写一句话，↵ 交给一个新会话
等你 1
  ● 登录页改版        mac-a    在问你：要不要保留旧的跳转？
在干活 2
  ● 修复导出超时      mac-a    #128
  ● 周报数据          linux-a
刚落地 1
  ✓ 升级依赖          mac-a    PR #131 已合并
▸ 已结束 4 个
↵ 切过去  Tab 操作  ↑↓ 选  打字筛选  ? 图例  esc 关  ↑ 到 ⚡
```

### 开一个会话

- **交一件新任务**：打开面板，在最上面的 ⚡ 行写一句话（比如「导出 CSV 时加上表头」），↵。fleet 记下这件任务，开一个新会话去做，你说的那句话就是会话收到的第一句。按 Tab 可以先选在哪个仓库里做、交给 Claude 还是 Codex。
- **开一个空白会话**：选「⚡ 新会话（空白）」那一行，↵。它不绑仓库，适合问问题、查资料、先聊清楚再说。
- **切到别的会话**：直接打几个字（名字、机器、状态都能搜），↵。不打字直接 ↵ 回到上一个看的会话。

### 会话的状态

面板按「你该做什么」分组：

| 分组 | 意思 | 你要做的 |
|---|---|---|
| **置顶** | 你自己钉住的 | — |
| **等你** | 会话停下来问你问题，或者等你同意某个操作；它在单上问了你、还没人回答的也在这里（哪怕它已经停下）。问题的原话写在下一行 | 切过去回答，或在那一行按 Tab →「回答」 |
| **在干活** | 正在做 | 不用管 |
| **等合并 / 等发版** | 做完了，PR 还没合，或合了还没上线；行尾写到了哪一步：检查中 · 检查红 · 可合并 · 等发布列车 · 部署中 | 一般不用管；检查红时切过去看看 |
| **刚落地** | 改动已经合并进仓库 | 看一眼结果 |
| **其他** | 空闲、读不到状态的 | — |
| **已结束** | 做完了的会话：没绑单的，或者单已关、PR 已合、过了一天的；窗口还开着的在上，已回收的在下，折在最下面 | 还开着的：最后一行 ↵ 一键回收；想接着做：选中 ↵「恢复」 |

一行后面会标它在哪台机器（`mac-a`）、对应的单号（`#128`）或 PR。一台机器连不上时，面板顶上会出现一整条红字，那几行标「失联 N 分钟」；等它恢复就好，会话没有丢。

### 一个会话能做的事

选中一行按 **Tab**，是这一行的菜单：进入 · 在它的目录开 shell · 打开 PR · 回答 · 发一句话 · 改名 · 置顶 · 改回收方式 · 停下（可恢复）· 继续 · 唤醒 · 换账号 · 换成 Claude / Codex · 回收。「在它的目录开 shell」开在会话所在的那台机器上。

在终端里也可以用命令做同样的事（`<会话>` 写名字的一部分、`#单号` 都行，认不出是哪个时会列出候选，不会乱猜）：

```sh
fleet ls              # 我的会话：名称 · 单号 · 机器 · 剩余 · 状态 · PR · 回收方式
fleet ls --all        # 连已结束的一起
fleet open 登录页      # 打开客户端并切到这个会话
fleet answer 登录页 保留   # 不进会话直接回答它的问题
fleet close 周报       # 关掉一个会话
fleet quit            # 退出 fleet（见下）
```

## 在代码仓库里干活

交给仓库的任务，会话在**自己的一份代码副本**里改，不碰别人的；做完自己开 PR，检查通过后自己合并，然后告诉你结果。你在「刚落地」里看到它，在 PR 上看改了什么。

你不用盯着它。要它停下、换个方向，切过去直接说；它卡住时会出现在「等你」里。

## 关掉电脑、换电脑、在手机上看

会话跑在 fleet 的机器上：关掉终端、合上笔记本、换一台电脑或在手机上打开，都还是那一套会话。怎么连、关掉后怎么回来，见 [电脑和手机上怎么连](connect.md)。

## 任务记录：T 号

你在 ⚡ 行交出去的每件事，fleet 都先记一笔，编号 **T** 开头（比如 `T42`）。记下的是你的原话、交给了哪台机器、哪个会话、现在什么状态。

- 交给仓库的任务会同时有一张单子（`#128` 这样的单号），面板上显示单号；不绑仓库的显示 T 号。
- 在入口网页的 **任务** 页能看到你所有的任务记录，会话结束了记录还在。
- 跟同事说「T42 那件事」，对方在任务页就能找到。

## 回收：会话什么时候关

会话做完会被自动收走，不用手动清理。收走前先记下历史，代码副本留着，在面板「已结束」里随时能 ↵ 恢复。默认规则：

| 会话 | 默认什么时候关 |
|---|---|
| 仓库任务，PR 合并了 | 合并后约 10 分钟 |
| 仓库任务，做完了但没有 PR | 空闲 2 小时 |
| 空白会话 | 空闲 15 分钟 |

想改：选中那一行 Tab →「改回收方式」，可以选 **合并后关**、**做完就关**（可以带时长）、**循环停了关**、**到某个时间关**、**不自动关**。正在干活、正在等你回答的会话不会被收走。

## 额度和用量

面板顶上那一行只说你正在看的这个会话：剩多少上下文、用的哪个模型（比如 `剩余 62% · Opus 5.5 · high`）。灰色表示这个读数是 5 分钟以前的。

上下文快满时，仓库任务的会话会自己交接给一个新会话接着做；空白会话里你也可以直接说「交接一下」。

## 可选：把常用动作设成单独的键

默认只有打开面板这一个键，其余都在面板里。习惯了旧的快捷键，可以在自己电脑的 `~/.config/claude-fleet/fleet.conf` 里加回来：

```ini
[client]
FLEET_KEYS_EXTRA="next=cmd+down prev=cmd+up new=cmd+n"
[common]
FLEET_KEYS_PHONE_EXTRA="ctrl+]n=next ctrl+]b=prev"
```

可以设的动作（这张表也是生成的）：

<!-- docs-gen:keys-extra -->
| 名字 | 做什么 | Mac 上（⌘） | 手机上（⌃] 再按） |
|---|---|---|---|
| `next` | 下一个会话，右侧立刻跟过去 | `⌘↓` | `⌃] n` |
| `prev` | 上一个会话 | `⌘↑` | `⌃] b` |
| `back` | 后退：回到刚才看的会话（没有任务列表时：上一台机器） | `⌘[` | `⌃] h` |
| `fwd` | 前进 | `⌘]` | `⌃] l` |
| `new` | 新会话：在家里的机器开一个不绑仓库的会话，光标就在它的输入框；FLEET_COMPOSE=1 时是右边的写作区 | `⌘N` | `⌃] c` |
| `dispatch` | 派一件事：一行标题 + 仓库（默认上次用的）+ 可选交给 Codex，↵ 建单并开工；任何窗口都能按，不经过模型 | `⌘T` | `⌃] t` |
| `quit` | 退出 fleet：关掉这台电脑上客户端的全部进程（侧栏、hub 循环、连接），远端会话照常在机器上跑；fleet 重新进入 | `⌘Q` | `⌃] q` |
<!-- /docs-gen:keys-extra -->

不用 iTerm2（比如 Ghostty、系统自带的终端）时 ⌘ 键到不了 fleet，用 `⌃] p` 或 `⌃空格` 打开面板。

## 出了问题怎么说

- **一句话告诉维护者**：在任意一个会话里输入 `/fleet-feedback`，后面跟你想说的话，比如 `/fleet-feedback 手机上面板打开很慢`。它会先给你看要发出去的内容（哪些会公开、哪些遮掉了），再问要不要附上最近的日志和屏幕，你确认了才发。发出后你会拿到一个反馈号（`F` 开头），处理完会回到你的会话里。
- **连不上、打不开**：先看 [故障排查](../troubleshooting.md)。需要别人帮你看时，在终端敲 `fleet debug report`，它会把诊断信息（已去掉密钥）交给入口，给你一个短链接，把链接发给管理员。
- **常见疑问**：[常见问题](../faq.md)。

无仓库的编排会话也可以在列表菜单中换成 Codex。原会话要先结束当前回合；有原生定时任务时，面板会请它核对当前任务、准备交接笔记，再完成切换。准备期间原会话继续运行；登录、目录信任或任务信息不全时会说明原因。会话内的循环巡检与单次提醒分别保留时间和到期规则，已删除的任务不会接续。若项目中有 Claude 持久提醒，面板仍会请原会话核对任务并准备笔记，随后说明无法核验接续执行者并拒绝切换；原会话和提醒继续运行，不要求你查找或手工导出 JSON。可信节点会补齐 HOME 的目录信任，保留你明确设置的不信任或关闭预信任的选择。未发送的输入会保留为草稿。
