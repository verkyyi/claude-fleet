# 电脑和手机上怎么连

会话跑在 fleet 的设备上，不在你的电脑或手机上。你的电脑和手机只是打开它们的窗口：同一个账号，在哪台设备上打开，看到的都是同一套会话。要在终端里敲的命令，都集中在这一篇。

## 电脑上（Mac 或 Linux）

**第一次**：把管理员发来的那一行粘进终端，回车。管理员自己装，用入口地址后面加 `/install`：

```sh
curl -fsSL https://hub.example.com/i/<邀请码> | sh     # 成员：邀请里的那一行
curl -fsSL https://hub.example.com/install | sh        # 管理员
```

装完会打开 fleet，请你登录一次：终端里出现一个链接或二维码，用浏览器打开或手机扫，用微信、邮箱或 GitHub 登录，点 **确认签发**。看到 `✓ 证书 · ✓ 已登记到入口` 就连上了。

**之后每天**：在终端敲

```sh
fleet          # 打开，回到上次的样子
fleet quit     # 只退出这台电脑上的窗口，会话照常干活
```

Mac 上推荐用 iTerm2，⌘P 打开总面板；别的终端用 `⌃空格` 或 `F12`。

## 关掉电脑会怎样

| 你做了什么 | 会话 | 回来时 |
|---|---|---|
| 关掉终端窗口、合上笔记本、断网 | 照常干活 | 敲 `fleet`，回到原样 |
| 面板里选「退出 fleet」，或敲 `fleet quit` | 照常干活（只退了你这台电脑上的客户端） | 敲 `fleet` |
| 换一台电脑 | 照常干活 | 在新电脑上装好、登录（同一个账号），敲 `fleet`，会话全都在 |

登录一次管 12 小时，到期这台电脑自己续；续不上时客户端会请你再扫一次码。

## 手机上（iOS 或 Android）

手机上用 **Termius**（iOS / Android 都有）连到你自己的地址，看到的就是电脑上那一套会话。第一次设置一次，大约 5 分钟：

1. 在浏览器里打开入口，登录后点导航里的 **从手机连**（地址是 `https://<入口>/fleet/keys`，比如 `https://hub.example.com/fleet/keys`）。
2. 照页面走六步：装 Termius → 在 Termius 里生成钥匙 → 把公钥贴回页面 → 在 Termius 新建主机（地址、端口、用户名、钥匙四项，页面上每项都有复制按钮）→ 连接，信任主机钥匙 → 连上后按 `⌃] p` 打开面板。
3. 你的地址形如 `<名字>.<入口给的域名>`（比如 `alice.fleet.example.com`），页面上写着；端口也以页面上写的为准。

之后在手机上：

- 打开面板：`⌃空格`（在 Termius 里先点 Ctrl 再点空格）、`F12` 或 `⌃] p`。把 `F12` 放到 Termius 键盘上方那一排，点一下就开。
- 屏幕窄时面板自动全屏，点一行就切过去。
- 换手机、丢了手机：在入口的 **我的连接** 页撤掉那把钥匙，立刻就连不上了。
