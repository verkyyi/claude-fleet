# 服务健康

## 打开健康页

直接打开本站的 [/status](/status)，无需登录。ClaudeFleet 显示中文，tokenman.io 显示英文。页面每分钟自动更新，公开数据最多会有约一分钟缓存延迟；官网页脚和头像菜单里的「服务健康」也通向这里。

## 看懂状态

「正常」表示所有探测最近都成功；「降级」表示至少一项失败、尚未接入，或数据超过三分钟未更新；「故障」表示三个用户入口都探测失败。没有数据不会显示正常。

页面分别显示入口、微信扫码登录、微信服务连接、运维通知和发布服务的状态。探测从服务端发起，不代表你所在网络的全部体验；服务端本身不可用时，页面也可能无法打开。更新失败时会提示旧数据。

## 首次回复与家机器

首次回复是从网页点击「开始」到第一段回答显示出来的时间，包含开会话和进入会话页面的等待。p50 表示一半样本不超过这个时间，p90 表示九成样本不超过这个时间。公开页显示近 24 小时和近 7 天的 p50 / p90，不公开样本数量；暂无样本显示「—」，不是零秒。

统计只包括十分钟内收到回答且成功上报的网页会话。空会话、提前关闭网页、超时或被浏览器阻止的上报不计入，因此它不是所有启动尝试的成功率。样本少时，分位数不能代表稳定水平。

公开页显示近 24 小时服务端到家机器的整体平均、最高往返延迟和失败率，不展示单台机器、人数、机器数或其他可识别信息。最新采样小时过旧会提示。

点「显示登录后的信息」可额外查看「你的家」；尚未登录会提供登录入口。它只显示你自己的连接，其他人的家不可见。管理员登录后还可查看匿名机器汇总和运维明细。这些额外信息不进入公开缓存；原 `/app/health` 登录入口继续可用。

## 事件与说明

连续三次每分钟探测失败后，系统记录一条事件；持续失败不会重复开事件。第一次成功后自动标为「已恢复」。页面列出近 7 天发生或恢复的事件，以及仍在处理的事件。管理员可以补充中英文公开说明。说明对任何访客可见，请只写服务影响和进展，不填写机器名、登录名、内部地址、IP、令牌或用户身份。

运维告警沿用现有通知通道，在 ops 收件箱查看；没有新增企业微信推送。管理员还可以看到每日、按 Agent 的首次回复分位数、最近探测、发布记录和本副本的请求与数据库连接池数据。RDS CPU 和额度暂未接入。
