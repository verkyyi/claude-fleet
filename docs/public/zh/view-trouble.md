# 看台出问题时

看台（`fleet` 打开的那个界面）坏了，会话不受影响——它们照常在家里那台机器上跑。你要的只是一个能敲命令的地方。按情况从上往下：

## 1. 看台还开得起来：⌃\

在看台里按 `⌃\`，开一个命令行，不用离开看台。

## 2. 看台反复起不来：自动落到命令行

- 电脑上的 `fleet`：家机器连得上、看台却连续 3 次没起来（或起来不到一分钟就退出），就不再重连，直接把你放到家机器的命令行，并说一行为什么；在那里输入 `exit` 回看台。
- 手机 / ssh App 走入口端口：看台意外退出时留在家机器的命令行，不断开；输入 `fleet` 回看台。

## 3. 看台整个打不开：`fleet shell`

在 Mac 上（或任何装了 `fleet` 的电脑上）输入：

```sh
fleet shell            # 家里那台机器的命令行（$HOME），不经过看台
fleet shell mac-a      # 点名别的机器
fleet shell --print    # 只打印一行等价的 ssh 命令，给手机 / iPad 上的 ssh App 用
```

- 走的是看台同一张连接证书、同一条线路；不开新端口，不加长期钥匙。
- 入口（hub）连不上时，用这台电脑上次记住的线路；证书过期了就只走那台机器的入口端口（用这台电脑自己的钥匙）。那台机器没有入口端口时会直接说「入口不在时进不去」，不会乱试。
- 进去后输入 `fleet` 回看台。
- 只开命令行：不建会话，不改任何记录。

还是不行，看 [故障排查](troubleshooting.md)。
