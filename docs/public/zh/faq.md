# 常见问题

问答只写在这一页。官网首页的问答、给搜索引擎的结构化数据和给 AI 读的 `llms.txt` 都从这里生成，不另抄一份；标着「官网」的几问会原样出现在官网首页。

## 先了解

### 为什么要申请才能用？
<!-- faq: site -->
Tokenman 目前限定开放：每个账号背后是一台真机器和真额度，我们按照顾得过来的人数一批批放开。想用就申请：说说你想用它做什么，通常 1 个工作日内答复；用微信登录的，结果发到你的微信。申请只保存你的登录方式、表上填的内容和审核结果。

### 和自己装 Claude Code 有什么不同？
<!-- faq: site -->
同一个官方 Claude Code，机器、技能和发布由 fleet 配好；每件事一个会话，关掉电脑它也继续跑。

### 不会编程能用吗？
<!-- faq: site -->
能，用平常的话说要什么就行；改代码、开 PR 是可选的，只对话、做页面和文档也行。

### 要自己的 Claude 订阅吗？
<!-- faq: site -->
可选自带订阅：可以用我们提供的订阅，也可以接上自己的 Claude 或 ChatGPT 订阅；都是用订阅登录，不需要 API 密钥。

### 托管和自托管有什么区别？
<!-- faq: site -->
托管是我们为你们公司开一个专用入口，你只管接订阅、给同事开号；自托管是你们在自己的机器上装同一套开源程序，入口、机器和数据都在你们手里。

### 我的代码和文件放在哪里？安全吗？
<!-- faq: site -->
代码和文件在跑会话的那台机器上、你自己独立的系统账户里，别人看不到；订阅的密钥由入口保管，不进会话，操作有记录。

### 断网或离线能用吗？
会话要连得上 Claude 或 ChatGPT 的服务才能干活；自托管时只用一台电脑可以不要入口，也可以不连 GitHub。

### 是 Anthropic 官方产品吗？
<!-- faq: site -->
不是，fleet 是独立的开源项目（MIT），运行未经修改的官方 Claude Code；Claude 是 Anthropic 的商标。

## 用起来

### 一台电脑能跑多少个会话？
默认不设固定上限：新会话开之前先看这台电脑还剩多少内存、负载高不高，装不下就排队等，已经在跑的会话不受影响。想要一个硬上限，可以在配置里写 `FLEET_GLOBAL_MAX_SESSIONS`。

### 关掉终端，会话还在吗？
在。会话跑在机器上，不跑在你的终端里；下次敲 `fleet` 回到原样，落在你上次看的那个会话（它已关掉就开一个新的）。`fleet quit` 只退出客户端，会话照样在跑。

### 没有 GitHub 能用吗？
能。只对话、做页面和文档的会话不需要 GitHub；要让会话在代码仓库里改代码、开 PR，才需要装 `gh` 并 `gh auth login`。GitHub 只放代码和 PR，任务和会话都在入口上；GitHub 连不上时什么照常、什么在等，见 [故障排查](troubleshooting.md#github-连不上的时候)。

### 会话停在一个问题上不动了怎么办？
它多半在等你回答（要你选一个方案、批准一个操作）。⌘P 面板里「在等你的」一栏列着它们，选中那一行就能看到它在问什么。

## 自托管

### 自托管最少要准备什么？
一台 macOS 或 Linux 电脑、一个 Claude 或 ChatGPT 订阅，以及登录过一次的 `claude` 或 `codex` 命令行。只有一台电脑时不需要入口，照 [自托管 · 快速开始](self-host/quickstart.md) 十分钟左右能开出第一个会话。

### 什么时候需要自己架入口？
要把几台机器连起来、给同事开号、在网页控制台或手机上看会话时。入口是一个程序、一个端口，数据放 SQLite 或 Postgres；步骤见 [安装与部署](self-host/install.md)。

### 自托管的入口会显示官网吗？
不会。自托管入口的首页直接是控制台；官网只在我们自己的入口上。

### 怎么升级？会打断正在跑的会话吗？
机器和客户端都跟随稳定版：`fleet update` 立刻跟上，不跑也会自己跟上。换版只换程序和后台服务，不重开正在跑的会话。

### 哪里坏了怎么查？
先跑 `fleet doctor`，每一行是什么、红了怎么办都在 [故障排查](troubleshooting.md)；要别人帮你看，把 `fleet doctor --json` 的输出发给管理员。
