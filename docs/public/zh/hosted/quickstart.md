# 托管管理员 · 快速开始

目标：用为你们开好的入口，接上订阅、给第一位同事开号，让他开出第一个会话。你只需要一台电脑和浏览器，不用自己架服务器。

下文的 `https://hub.example.com` 换成你们入口的地址（开通时发给你的那个）。

## 1. 登录入口

1. 浏览器打开 `https://hub.example.com/signin`。
2. 用开通时登记的方式登录：微信扫码、邮箱，或 GitHub。
3. 登录后进到控制台。左边栏「管理」一组（订阅池、服务节点与客户端、使用者……）只有管理员看得到。

使用 tokenman.io 公共门户时，首页按浏览器语言显示中英文；页脚切换语言后会记住。

点「登录」可选微信扫码、邮箱或 GitHub，也可从首页申请使用或体验（开放试用时）。旧门户书签会转到相同页面；微信内仍保留原入口。

## 2. 装上客户端

开号、发邀请用的是 `fleet` 命令。在你自己电脑的终端里：

```sh
curl -fsSL https://hub.example.com/install | sh
```

装完它会打开 `fleet` 并让你登录一次（浏览器或手机扫码，点 **确认签发**）。

## 3. 接上订阅

会话用的是 AI 订阅（Claude 或 ChatGPT）：可以用我们提供的，也可以接上你们自己的。入口替你们保管凭据，按人分配额度。

1. 控制台打开「订阅池」页。用我们提供的订阅时，开通时就已经在这里；接你们自己的，照 [订阅与额度](../admin/quota.md) 加。
2. 能看到订阅和它的 5 小时 / 7 天额度，就接好了。
3. **放行**：新使用者默认一个订阅都不能用。给同事开号后，在「使用者」页点他 → 订阅授权，选「全部订阅」。

有几个订阅就加几个；一个订阅的额度快用完时，入口会换到下一个。

## 4. 给同事开号

控制台「使用者」页 → **生成邀请命令**，或在终端里：

```sh
fleet hub invite <他的 GitHub 账号>                  # 生成一条邀请
```

`fleet hub` 要你的管理员凭据：浏览器登录入口后，把 `ccq_sess` cookie 的值 `export FLEET_HUB_SESSION=<值>`（详见 [管理员手册](../admin/index.md)）。

- 邀请 7 天内有效、只能用一次；写了 GitHub 账号的话，只有他本人能用。
- 他用邀请登录时，入口自动在一台机器上给他开好账号，你不用另外开。
- `fleet hub invite --list` 看所有邀请的状态，`--revoke <id>` 作废一条没用过的。

把打出的那一行安装命令发给他，形如：

```sh
curl -fsSL https://hub.example.com/i/<邀请码> | sh
```

接下来他照 [成员 · 快速开始](../member/quickstart.md) 走。

## 5. 确认他走通了

- 控制台「使用者」页上能看到他，订阅授权已放行。
- 他的第一个会话出现在控制台的会话列表里。
