# fleet 帮助

登录以后，在对话里说一句要做的事，会话会替你做完，做完提醒你；在电脑或手机上都能看、都能接着说。下面按你是谁找起点。

## 用起来

| 你是 | 从这里开始 |
|---|---|
| **成员**：收到一条邀请 | [第一次登录到第一个会话](member/quickstart.md) · 之后看 [日常使用](member/usage.md) |
| **管理员**：管人、订阅和额度 | [开号、接订阅、看用量](hosted/quickstart.md) · 之后看 [管理员手册](admin/index.md) |
| **想在手机或另一台电脑上接着用** | [电脑和手机上怎么连](member/connect.md) |

几个词：

- **会话**：一个替你干活的 AI（Claude 或 Codex）。关掉电脑它也照常做。
- **任务**：你交代的一件事。每件任务一个会话，做完会提醒你。
- **设备**：会话真正跑在哪台机器上。你不用挑，fleet 替你安排。
- **额度**：订阅在 5 小时 / 7 天里还能用多少。管理员给每个人分。

遇到问题：[常见问题](faq.md) · [故障排查](troubleshooting.md)
