# fleet 文档

fleet 让一个小团队用自己的 AI 订阅（Claude Code、Codex）同时推进很多件开发任务：每件任务一个会话、一份独立的代码副本，所有会话在一处看见——谁在干活、谁在等你回答，一眼可知。

先找到你是哪一类读者，从对应的「快速开始」走到第一个会话：

| 你是 | 你的情况 | 从这里开始 |
|---|---|---|
| **自托管团队** | 想在自己的机器上跑 fleet：可以只有一台电脑，也可以自己架一个入口连起几台机器 | [自托管 · 快速开始](self-host/quickstart.md) |
| **托管客户的管理员** | 已经拿到为你们开好的入口地址，要接上订阅、给同事开号 | [托管管理员 · 快速开始](hosted/quickstart.md) |
| **成员** | 管理员发给你一条邀请，想开出自己的第一个会话 | [成员 · 快速开始](member/quickstart.md) |

## 几个词

- **会话**：一个正在做事的 Claude Code 或 Codex。每个会话有自己的窗口，关掉客户端它也照常跑。
- **入口**：把多台机器、多个人连起来的那台服务，网页控制台也在这里。只用一台电脑时可以没有入口。
- **承载**：一台电脑除了看会话，还亲自跑会话。
- **客户端**：你在终端里敲 `fleet` 打开的那个界面。
