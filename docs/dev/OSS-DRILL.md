# 照对外文档从零装一遍 · 演练单（OSS-DRILL）

> 对内文档（`docs/dev/`）。由 issue #3588（EPIC #3569 C18）立账。
> 目标：一位没参与过开发的同事，只看 `docs/public/`，两类读者都不问人走到第一个会话。
> 成功 = 下面两张表各有一次「无人提示、走通」的记录；卡住的每一处都有一个修复 PR，修完从头再走。

## 规则

- **演练人只看对外文档**（`docs/public/zh/`，或渲好的 `/docs/`）。不读 `docs/dev/`、不读代码、不问开发者。
  卡住超过 10 分钟，或要问人才能往下走，记一次「卡住」，写下问了谁、问了什么，然后才可以问。
- **版本**：演练前先确认 `stable` 已经包含全部对外文档的合并（C7–C12）——文档里的安装命令拉的是 `stable`。
  记下 `git rev-parse --short stable`。
- **自托管路全程不碰我们的入口与中转**：演练结束后，把云主机和 Mac 上的出站日志（或 `tcpdump` / 代理日志里的主机名）
  交给 `bin/oss-scan.sh` 的规则表查一遍，查不到我们的地址才算过。
- **凭据不进这张表**：表里只写「拿到了 / 用了哪一种」，不写值。
- 每卡住一处：先派一件任务（`task` 工具），修复 PR 合了、`stable` 挪过之后，**从头**再走一遍，另起一行记录。

计时从演练人打开第一篇文档开始，到第一个会话里看到 Claude 的回复为止。
