## 沿用当前安装版本的样式

已只读核对本机运行安装 `b62e1e755eb1` 中的面板、`SessionList.tsx`、`Shell.tsx`、Sidebar 组件和主题源码；未把仓库最新代码直接当作已部署页面的截图证据。

- Terminal 运行标记沿用 `↻`，不再用既有含义是退出的 `◌`。普通图标继承行色，需要回答沿用红色加粗 `!`，选中沿用反白。Loop 使用同一个左侧状态槽的 `⟳`；并存时按状态优先级只显示一个符号，终端不模拟 CSS 旋转。
- Web 运行标记沿用 16px Loader 与 2.4 秒线性旋转；需要回答沿用 CircleAlert 线框和 clay 色。Loop 采用同一线框风格的循环箭头，不重新造彩色徽章。
- Web 桌面沿用 20rem 侧栏、32px 紧凑行和浅色 accent 选中底色；手机沿用 44px 行和 muted 选中底色。标题和留白沿用现有层级，普通静止行继续不加状态标签。
- 原型内嵌 SVG 仅用于展示，实际实现复用现有组件、图标和主题变量。待启动使用同一状态槽内的低对比时钟符号；PIN、普通任务无标题及旧会话收纳规则不变。

## 列表结构

两端一致：**PIN 在前 → 普通任务直接排列 → 更早的会话折叠入口**。

- 只有 PIN 显示一个轻量标题；无 PIN 时连这个标题也不显示。
- 非 PIN 不显示标题、数量栏或分组工具条，用少量留白衔接即可。
- 不按运行、等待、审批、失联等状态分组。每行一个 Task，没有 Batch、父子树、EPIC driver 或协调者身份。
- 保留底部「更早的会话」，默认折叠。它只是较旧任务的收纳，不表示已完成、已取消或不能再继续；一个 Task 的多次 Coding Agent Session 仍在该 Task 的详情内，不重复拆行。
- PIN、运行中、需要回答、Loop、待启动、有自动唤醒计划或观测不明的任务，不默认收入旧会话。原型用旧记录样例验证折叠，生产沿用现有历史收纳依据，不另加任务终态。
- 搜索涵盖折叠历史，命中直接显示，不要求先展开。无搜索时恢复原折叠状态。
- 状态变化只更新行内提示，不让任务重新排序。PIN / 取消 PIN 是显式操作，跨区后仍选中同一 Task。历史里的任务明确继续执行后回到普通列表，打开查看本身不启动执行。

## 行内只给必要提示

标题是主要信息。正常静止会话不加 `idle`、`exited`、`非运行中`、完成文案、下一次时间。

实时行以当前原生观测为准：旧结果中的 failed、blocked、succeeded 或 cancelled 不覆盖正在运行、空闲、未知或当前待回答状态。旧结果保留在历史与详情中，旧 blocked 不制造新的待回答请求。此修正已覆盖 tmux 的 ID/Task 结果回填及 Web 兼容列表；当前绑定与旧 Asked 来源修正已随 #5385 合并，发布核验见完整方案。

| 提示 | 含义 | 位置与行为 |
| --- | --- | --- |
| Terminal `↻` / Web Loader | 当前正在运行 | 左侧沿用现有图标位和样式；不再重复显示 `active / working` 文案 |
| Terminal `!` / Web CircleAlert | 需要我回答，包括原生审批或待答问题 | 同一左侧状态槽，使用现有强调色；详情解释具体请求 |
| Terminal `⟳` / Web 循环箭头 | Loop 已开启，之后还会循环执行 | 同一左侧状态槽，低对比；循环间歇也保留，单次定时不冒充 Loop |
| Terminal `◷` / Web Clock | 已提交执行请求，但还未开始执行 | 同一左侧状态槽，含「待启动」可读名称；本次请求的原生执行被确认启动后消失 |

每行只在左侧一个固定位置显示一个状态符号，优先级为需要回答 → 待启动 → 运行 → Loop；静止且无安排时留空。事实仍可同时存在：运行中的 Loop 显示运行符号，等待回答的 Loop 显示 `!`，其他事实保留在无障碍名称、悬停、底部说明和详情。行尾不再重复任何状态标记。

待启动来自已受理执行请求的事实，不是凭「没有 Session」推断。没有启动请求的草稿、没有新请求的 idle、停止后不再派发的任务，都不显示待启动。环境分配或容量排队，可以在详情中说明原因。停止待启动任务会撤销待派发请求，防止之后自动开始；UI 等回执，不先假报成功。首次提交以及明确继续/恢复/切换后等待执行均可显示。原型在「补充接口测试」展示首次提交场景。

行内没有提示不等于观测完整。失联的行沿用现有淡化处理，不额外增加大状态标签；hover、选中说明或详情明确「运行情况未知」及最后观测，不能伪装成非运行。自动唤醒未知也只在详情如实说明。

悬停和无障碍名称解释图标；手机可点击详情或长按，不依赖 hover。尊重减少动态效果设置。具体原生状态、是否会再次自动运行、单次计划、下次时间与时区和退出原因，进入 Terminal 底部说明或 Web 详情。

## iTerm2 / tmux

入口仍为 ⌘P，手机 SSH 终端沿用 F12 / ⌃] p。面板之外的键属于 iTerm2 和原生 Agent，不新增全局键。

保留 **图标 1 格 · 短码 8 格 · Agent 7 格 · 标题 · 仓库 13 格** 的列顺序、反白选中和 Tokyo Night / 既有浅色主题。所有状态共用第一个图标格，标题区和行尾不再放状态符号，不增加表头或新列。

Task 行使用固定的书面短码，网页链接携带 Task FID；继续执行和历史结果变化不改变任务地址。输入前缀在用户全部任务历史中解析，有多个候选则提示选择。受控 Task 仅以现有 `execution_owner` 选择当前会话；旧窗口、历史 Asked 和回收等待理由不生成当前回答标记。

```text
Search tasks…
─────────────────────────────────────────────────────────────
  ✦ Messages 4
  + New task
  $ Shell

  PIN
  ↻ NV03     Codex   Hub任务抽象简化                 claude-fleet
  ⟳ A7P4     Codex   检查服务可用性                  ops

  ↻ P4T8     Claude  修复历史会话                    claude-fleet
  ! K8D2     Claude  发布接口变更                     api
    M2R9     Claude  编写 API 界面                   web
    J6W1     Codex   调整登录页文案                  website
  ◷ B9C2     Codex   补充接口测试                    api
  ▸ 更早的会话

  ⇣ Unpin task
  ⇄ Language
  ⏏ Exit fleet
─────────────────────────────────────────────────────────────
NV03 · 运行中 · 不会自动运行 · Codex active
↑↓ select   Enter open   Tab actions   Esc back
```

消息、新任务、命令行及底部入口沿用现有位置。新建只选择 Agent / 环境并输入任务描述，不选角色或父任务。

Tab 仍进入同一面板内的全页动作菜单：打开、停止任务、继续工作、改名、切换 Agent、自动运行、产物、会话历史、归档。Esc 返回保留 Task、搜索和滚动。PIN / 取消 PIN 沿用原面板入口。

以终端物理宽度为准：≥60 列显示仓库；40–59 列隐藏仓库；小于 40 列再隐藏 Agent。输出保留末列不改变这些阈值；窄屏仍保留选中任务说明，不用建议加宽的提示覆盖。标题按显示单元截断，为少量提示留位置；不变成多行卡片。完整事实留在可换行的选中说明。

## Web

桌面保留暖白/clay 主题、左侧单行列表和右侧网页对话；品牌、额度、搜索、＋、底部个人菜单位置不变。普通会话无状态文字，只有上述必要提示。任务元数据仍在 hover / 详情，不增加大表格、筛选栏或常驻详情列。

手机首屏仍是同一单行列表、顶部入口和右下角新任务按钮。点击进入全屏对话，返回保留列表位置；长按沿用详情 sheet，对话顶部也能打开详情，触控目标至少 44 px。

网页对话顶部保留标题、详情、更多，显式提供「停止任务」。详情内有 PIN / 取消 PIN，内容依次是任务描述、当前会话与原生观测、自动运行、最近产物、会话历史。移除 Parent、成员、批次进度、协调者和多套终态字段。

删除网页「终端」切换和 `?view=term` 入口；旧链接回该 Task 的网页对话并给一次说明。Web 不支持的原生交互给出在 iTerm2 打开该任务的指引，不偷偷回退到网页终端，也不在原型中虚构可用的审批按钮。

## 停止与状态事实

停止随时可用，不要求先合并、先上报、先结束 Subagent 或解除 keep。停止执行、撤销 Loop / 单次唤醒 / 待派发请求和自动恢复，保留文件及历史；不额外确认。请求失败原地重试，远端失联只确认已撤销 Hub 授权，执行停止仍待远端确认。

窗口改名不改变停止权限：真实 worker 即使名为 home、dash、plan 或 backlog 仍可停止，真正的 home/panel 改名后仍按角色保护。FID 歧义与身份校验保留。

打开只查看/连接。继续是显式的一次执行，不恢复已撤销计划。关闭面板或网页只是离开视图；删除数据是另外的动作。停止和待启动提示都不增加 Hub 任务终态。

已停止且当前执行绑定为空的受控 Task，在网页顶部显示「继续」，更多菜单提供「用 Claude 继续／用 Codex 继续」。打开历史本身不发送启动请求。继续携带页面所见的原停止操作与代次，Hub 核验原生退出或从未领取的证明；失败不退回旧会话 resume 或新建任务。相同意图重试复用幂等键，成功只提示请求已提交，实际运行仍等原生观测。只读访问不可操作，新接续能力仍由节点能力检查控制。

## 实现与验证

原型本身不修改运行中的 iTerm2、tmux 或 Web；实际交付与验收进度见完整方案。

1. 修改现有面板和 `SessionList` 的 Task 投影，保留共享观测事实与当前唯一 Session 绑定；删除父子聚合。
2. 简化行内展示，恢复历史折叠，搜索覆盖历史，保留稳定选中；待启动读取已受理请求与本次原生执行开始回执。
3. 接入最高优先级停止，包括撤销尚未执行的请求；停止不受旧回收门限制。
4. 移除网页 Terminal 的专用入口与依赖，保留 iTerm2 SSH/tmux 和网页对话所需能力。

原型验证覆盖：仅 PIN 标题、历史折叠与搜索、静止行无标记、Loop 和单次定时区分、需要回答、待启动开始/停止、PIN 切换、状态变化不重排、Terminal 窄列和 Web 手机布局。HTML 按键不等于真实 tmux 验收；上线仍需真实 iTerm2、生产 Web、停止/失联/延迟派发等场景证据。

设计遵循 [产品方向](PRODUCT-DIRECTION.md)：保留现有接入和界面，把原生内部编排交回 Coding Agent。

跨任务回报、订阅和基于产物的自动触发不在本轮原型范围；任务顺序说明保留在正文，等实际需求出现再设计平台能力。
